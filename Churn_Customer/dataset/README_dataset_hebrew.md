# תיאור הדאטאסט — לקוחות נוטשים בחנות אונליין

## מקור

**שם הדאטאסט**: E-Commerce Customer Churn Analysis and Prediction  
**מקור**: Kaggle (ankitverma2010)  
**סוג נתונים**: אמיתי — נתוני לקוחות ממערכת CRM של חנות אונליין

---

## למה הדאטאסט הזה?

כל הניסויים הקודמים בפרויקט השיגו **ROC AUC ≈ 0.5** — כמעט אקראי לחלוטין. הסיבה: הנתונים הסינתטיים הקודמים שימשו לצורכי הדגמה בלבד, וה-label "לקוח חוזר" הוגרל רנדומלית ללא קשר לפיצ'רים.

הדאטאסט הנוכחי מכיל **נתוני חיזוי אמיתיים** — לקוחות שנטשו באמת הפגינו דפוסי שימוש שונים (פחות הזמנות, פחות שימוש בקופונים, ניקוד שביעות רצון נמוך יותר) לעומת לקוחות שנשארו.

## תיאור העמודות

### מזהה
| עמודה | תיאור |
|---|---|
| `CustomerID` | מזהה ייחודי של הלקוח — **לא משמש כפיצ'ר** |

### משתנה מטרה (Target)
| עמודה | תיאור |
|---|---|
| `Churn` | **1** = הלקוח נטש, **0** = הלקוח נשאר |

### פיצ'רים נומריים

| עמודה | תיאור | טווח ערכים |
|---|---|---|
| `Tenure` | ותק הלקוח בחודשים | 0–61 |
| `WarehouseToHome` | מרחק מהמחסן לבית הלקוח (ק"מ) | 5–127 |
| `HourSpendOnApp` | שעות ממוצעות בחודש באפליקציה/אתר | 0–5 |
| `NumberOfDeviceRegistered` | מספר מכשירים רשומים בחשבון | 1–6 |
| `SatisfactionScore` | ציון שביעות רצון (1–5) | 1–5 |
| `NumberOfAddress` | מספר כתובות שמורות בחשבון | 1–21 |
| `Complain` | האם הוגשה תלונה בשנה האחרונה (0/1) | 0 או 1 |
| `OrderAmountHikeFromlastYear` | אחוז עלייה בסכום ההזמנות לעומת שנה קודמת | 11–26 |
| `CouponUsed` | מספר קופונים שנוצלו בחודש האחרון | 0–16 |
| `OrderCount` | מספר הזמנות בחודש האחרון | 1–16 |
| `DaySinceLastOrder` | ימים שעברו מאז ההזמנה האחרונה | 0–46 |
| `CashbackAmount` | סכום קאשבק ממוצע (₹) | 0–325 |
| `CityTier` | דירוג העיר לפי גודל ופיתוח (1=גדולה, 3=קטנה) | 1, 2, 3 |

### פיצ'רים קטגוריאליים

| עמודה | תיאור | ערכים אפשריים |
|---|---|---|
| `PreferredLoginDevice` | מכשיר ההתחברות המועדף | Mobile Phone, Computer |
| `PreferredPaymentMode` | אמצעי תשלום מועדף | Debit Card, UPI, Credit Card, Cash on Delivery, E wallet |
| `Gender` | מגדר | Male, Female |
| `PreferedOrderCat` | קטגוריית מוצר מועדפת | Laptop & Accessory, Mobile, Mobile Phone, Others, Fashion, Grocery |
| `MaritalStatus` | מצב משפחתי | Single, Married, Divorced |

## תובנות מהנתונים

- לקוחות שנטשו נוטים לדרג שביעות רצון **נמוכה יותר** ולהגיש **יותר תלונות**
- ותק נמוך (`Tenure`) קשור חזק לנטישה — לקוחות חדשים נוטשים יותר
- לקוחות עם `DaySinceLastOrder` גבוה (לא הזמינו הרבה זמן) נוטשים יותר
- שימוש גבוה בקופונים וקאשבק מאפיין לקוחות **שנשארים**
