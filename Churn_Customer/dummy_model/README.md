## ניסוי — Dummy Baseline

### גישה

מודל `DummyClassifier` של sklearn — ללא למידה מהדאטה.
נבדקו שלוש אסטרטגיות:

| אסטרטגיה | הסבר |
|----------|------|
| `most_frequent` | תמיד מנבא 0 (נשאר) — המחלקה השכיחה ביותר |
| `stratified` | מנבא לפי התפלגות המחלקות בדאטה (83% / 17%) |
| `uniform` | מנבא 0 או 1 בהסתברות שווה (50/50) |

ולידציה: StratifiedKFold (5 folds, random_state=42)

### פיצ'רים

אין — DummyClassifier מתעלם מכל הפיצ'רים לחלוטין.

### תוצאות

| מדד | most_frequent | stratified | uniform |
|-----|-------------|------------|---------|
| Accuracy | 0.8316 | 0.7174 | 0.5078 |
| Balanced Accuracy | 0.5000 | 0.5033 | 0.5118 |
| Precision (נוטשים) | 0.0000 | 0.1736 | 0.1750 |
| Recall (נוטשים) | 0.0000 | 0.1804 | 0.5179 |
| F1 (נוטשים) | 0.0000 | 0.1769 | 0.2617 |
| F1 Macro | 0.4540 | 0.5032 | 0.4463 |
| ROC AUC | 0.5000 | 0.5033 | 0.5000 |
| PR AUC | 0.1684 | 0.1693 | 0.1684 |

##  מסקנות

**most_frequent** ממחיש את בעיית חוסר האיזון בצורה הכי ברורה: Accuracy של 83% נראה מרשים, אך Recall=0 על הנוטשים — המודל לא מזהה אף לקוח נוטש. מבחינה עסקית הוא חסר כל ערך.

**stratified** ו-**uniform** מגיעים ל-ROC AUC של ~0.50 בלבד — כלומר ניחוש אקראי מושלם.

**החסם התחתון שכל מודל אמיתי חייב לעקוף:**

| מדד | חסם תחתון |
|-----|----------|
| ROC AUC | > 0.50 |
| Recall (נוטשים) | > 0.18 |
| F1 Macro | > 0.50 |
| PR AUC | > 0.17 |
