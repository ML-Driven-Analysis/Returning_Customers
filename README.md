# Customer Churn Analytics Platform

## Where should a business invest its retention budget?

פלטפורמה זו מנתחת התנהגות לקוחות באמצעות מודלי Machine Learning מתקדמים במטרה לזהות גורמי נטישה מרכזיים ולחזות אילו לקוחות נמצאים בסיכון לעזוב.

באמצעות השוואת מודלים, ניתוח חשיבות מאפיינים ומדדי ביצועים מתקדמים, המערכת מספקת תובנות עסקיות המסייעות לארגונים למקד את מאמצי השימור שלהם במקום שבו ההשפעה העסקית צפויה להיות הגבוהה ביותר.
הפרויקט עוסק בעבודה על 2 dataset שונים, תחת Churn_Customers מופיע התוצר העיקרי.
